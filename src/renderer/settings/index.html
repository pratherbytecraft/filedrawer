AccessibilityLets Filedrawer see when Finder opens a window, and where.
Control FinderLets Filedrawer ask Finder which folder a new window shows.

Filedrawer opens in the same spot as Finder's window, so Finder's window only shows for a moment. Show in Finder from other apps opens Filedrawer too. Finder keeps running, since it draws the Desktop. While this is on, Filedrawer opens when you log in.
